# Smart To-Do List

Build this project yourself using HTML, CSS, and vanilla JavaScript.

## Files
- `index.html` — app structure
- `style.css` — styling and responsive layout
- `script.js` — task logic and localStorage

## Feature checklist
- [ ] Add tasks; reject empty input
- [ ] Add task by pressing Enter
- [ ] Mark tasks completed
- [ ] Edit tasks
- [ ] Delete tasks with confirmation
- [ ] All / Active / Completed filters
- [ ] Total / Completed / Pending statistics
- [ ] Persist tasks using localStorage
- [ ] Responsive mobile and desktop layout

## Run locally
Open `index.html` in your browser, or use VS Code Live Server.

## GitHub practice
Create an empty GitHub repository named `smart-todo`, then from this folder run:

```bash
git init
git add .
git commit -m "Start smart todo app"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/smart-todo.git
git push -u origin main
```

Replace `YOUR-USERNAME` with your GitHub username.
